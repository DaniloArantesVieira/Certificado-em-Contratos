# Política de segurança

## Escopo

Este é um projeto acadêmico e laboratorial. O repositório não oferece releases destinados a ambientes de produção.

## Relato de problemas

Problemas de segurança podem ser relatados pelos recursos disponíveis no repositório, sem incluir informações sensíveis. Ao descrever um problema, use dados fictícios ou remova qualquer valor secreto necessário à reprodução.

Nunca publique em Issues tokens, credenciais, certificados privados, chaves privadas ou outros segredos. Uma chave privada exposta deve ser considerada comprometida e substituída.

## Uso do laboratório

A configuração foi preparada para estudo e execução local. Ela não deve ser usada como referência de produção sem uma revisão adicional de segurança e dos requisitos do ambiente de destino.
